    Sobre GeoSolar

    Qué es GeoSolar

    GeoSolar ayuda a identificar terrenos con potencial fotovoltaico en Jaén, la provincia para la que se prepararon los datos del estudio. Es el proyecto 19 de Sistemas de Información Espacial.

    Cómo funciona

    • Evaluación territorial. Consulta las capas geográficas en el círculo seleccionado y calcula una puntuación TOPSIS.
    • Estimación satelital. Una red neuronal estima la aptitud a partir de un recorte de Sentinel-2 o de un TIFF que subas.
    • Buscar zonas candidatas. Muestra hasta tres alternativas con aptitud buena o normal, sin veto y dentro de la distancia elegida.

    Carga una zona de Jaén para comparar los dos análisis.

    Cómo leer los resultados

    • Aptitud. Una puntuación TOPSIS de 0 a 1 indica cómo se sitúa el terreno según los criterios geográficos. El modo satelital muestra probabilidades para las categorías «Buenos», «Normales» y «Malos».
    • Veto territorial. «Lugar prohibido» significa que se activa la regla de descarte de GeoSolar, que combina una intersección con Red Natura 2000 y determinados usos del suelo.
    • Veto estimado por IA. Es la probabilidad que el modelo asigna al descarte a partir de la imagen.
    • Sin datos. Faltan valores de uno o más criterios para calcular la evaluación territorial.

    Los dos modos pueden discrepar. La evaluación territorial consulta datos como la distancia a la red eléctrica. La red neuronal aprende patrones en los recortes y estima el resultado a partir de la imagen.

    Datos y metodología

    La evaluación territorial se apoya en las capas preparadas para Jaén. La estimación automática requiere que el mosaico Sentinel-2 cubra todo el círculo.

    • Capas de evaluación y mosaico Sentinel-2
    • Cartografía de referencia de Andalucía (DERA)
    • Límites provinciales del IGN
    • Repositorio de GeoSolar
    Cómo se calculan la puntuación y la estimación

    TOPSIS compara cada zona con perfiles de referencia a partir de la irradiación, el número de curvas de nivel y la distancia a carreteras y a la red eléctrica.

    La red neuronal convolucional (CNN) se entrenó con pares de recortes satelitales y etiquetas generadas mediante la evaluación territorial. Estima la aptitud y el veto a partir de esos patrones.
